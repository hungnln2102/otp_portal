# Mavryk · 4 Seasonal Anime Interfaces

Mở trực tiếp một trong các file sau bằng trình duyệt:

- `spring.html` — Mùa Xuân
- `summer.html` — Mùa Hạ
- `autumn.html` — Mùa Thu
- `winter.html` — Mùa Đông

Các file dùng chung `season.css`, `season.js` và thư mục `assets`.

Animation hiện tại là motion loop riêng theo mùa:

- Xuân: cánh hoa
- Hạ: hạt sáng và chuyển động không khí nhẹ
- Thu: lá rơi
- Đông: tuyết rơi
